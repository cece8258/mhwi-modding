# 中性化处理说明（**不列出第三方原名**）

本文件公开发布前做过一轮中性化处理，共 **42** 处：

| 类别 | 处理 |
|---|---|
| 本机绝对路径 | → 中性占位（`旧工程目录` / `<模组管理器>` / `<7-Zip 完整版>` …） |
| 私有工程与试验号 | → `第N版` / `试验NN` |
| 第三方模组与作者名 | → `参考包A/B/…`（**对照表不公开**） |
| 付费 / 第三方素材名 | → `某套装` / `某头发素材` / `某袜素材` |
| R18 与身体部位直白词 | → 中性词 |
| 对**具名作品**的技术判断 | → 改成中性统计口径（例："作者误用 X" → "语料里 N/M 用了 X"） |

★ **原样保留、一个数字没改**：样本量、百分数、字节偏移、字段取值、判据与实测数字。
★ 文中 `参考包A/B/…` 是**匿名编号**，与任何具体作品的对应关系不在本仓库内。
