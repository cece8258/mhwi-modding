# MHWI 模组制作：笔记 + 流水线工具

《怪物猎人世界：冰原》**玩家模型替换模组**（`pl040_0010` 一类）的制作笔记与一套可复用的 Blender 脚本。

内容来自一条走到今天的实作路线（**通用手册 + 17 次实战记录**）：
借壳移植一套服装 / 头发、四部位权重对齐、mrl3 / ctc / tex 就地打补丁、悬挂件物理链、
材质观感与色彩空间、描边壳，以及"只有成品包、没有工程"时的反推。

> **本仓库只有文本与代码。**
> 不含任何游戏本体文件（`mod3` / `mrl3` / `ctc` / `ccl` / `tex`）、不含任何第三方素材、
> 也不含任何他人的模组文件。缘由与发布边界见 [NOTICE.md](NOTICE.md)。

## tools/ 是什么

一条可重跑的流水线：**采集 → 构建（搬件/建链/拆件/描边壳）→ 贴图烘焙与 `.tex` 编码 → mrl3 指向 →
ctc 物理链 → 导出 → 打包 → 从 zip 反向验收**，外加权重修复类与诊断类脚本。

其中几条是这几轮新加的：

| 脚本 | 作用 |
|---|---|
| `Z32_衣物权重对齐身体.py` | 衣物逐顶点抄最近皮肤顶点的权重（BVH 最近面 + 重心插值）；**悬垂件不要列进来** |
| `Z35_裙跟腿限幅.py` | 给"裙子跟腿"设上限（中缝 0%、越往外线性升到 `CAP`）；解决"岔腿时裙子中间被拉长" |
| `Y8c_链骨权重体检.py` | 链骨权重是否沿链渐变；**链轴要取链节点折线**，不能用 `末骨tail − 首骨head` |
| `Y8b_袖子穿模体检.py` | 静止姿态配点对，逐姿态量"点对距离的变化量"（不会被最近特征跳变带偏） |
| `Z14_四包终验.py` | 从 zip 反向验收：逐条目 CRC + 活材质指向的贴图一个不缺 |

依赖：**Blender 4.2 LTS** + [MHW_Model_Editor](https://github.com/chikichikibangbang/MHW_Model_Editor) 插件
（唯一必需插件）+ `texconv`（DirectXTex）+ 纯 Python 部分的 `numpy` / `Pillow`。

用法：先改 `tools/_config.py`（**所有路径都集中在那一个文件**），然后

```bash
cd tools
bash Z9_出一版.sh 我的包名 [开关...]
```

各步的作用、顺序、以及"顺序为什么不能换"都写在 `Z9_出一版.sh` 与每个脚本的文件头里。

## 三条最值得先看的

1. **`mhwi-mod-anatomy/SKILL.md` 的"可信度分级"** —— 哪些结论是几百张样本背书的（可以直接抄），
   哪些只是"存在这种写法"（只能当参考）。这份笔记里所有数字都注明了样本量。
2. **`mhwi-blender-modding/SKILL.md` 的"最贵的一条教训"与"判据事故"几节** ——
   症状治不好时，**先造一个能区分假设的测量**，并且**先标定你的判据回路**
   （故意做一个必然可见的改动，确认度量会变），比继续按"听起来合理"的猜测动手快得多。
3. **`实战/` 里的"指标无效"实例** —— 一个有符号体积、一个"腿皮露出率"、一个"最近距离"，
   都曾在**看起来合理**的情况下给出与事实相反的信号；每条都写了后来怎么换判据。
